# 任務日誌：建立 Budget CRUD 功能

## 任務目標 (Goal)
建立全新的 Budget (預算) 功能模組，支援 CRUD 功能，並整合 Mock API 與 i18n 語系。

## 執行動作 (Actions Taken)
1. 執行 `domain-scaffolder` 腳本建立 `src/domain/budget` 架構。
2. 於 `src/domain/budget/types.ts` 定義 `Budget` 型別。
3. 建立 `src/mock/budgetMock.ts`，實作 CRUD 的假資料與 MSW API 端點，並註冊於 `handlers.ts` (完成 `mock-api-generator` 規範)。
4. 修改 `src/locale/language.ts`，加入 `budget` 的中英文語系檔 (完成 `i18n-generator` 規範)。
5. 實作 `src/domain/budget/services/budgetApi.ts` 來串接 Mock API。
6. 實作 `src/domain/budget/pages/budget.vue`，使用 Ionic 組件與 Vue Query 來抓取預算列表與刪除功能，並套用 CSS Modules 與 Design tokens (遵循 `ui-standardize` 紀律)。

- `tasks.md` 因 Big5 編碼問題導致無法直接讀取，已改用 PowerShell 寫入。
- CRUD 新增與編輯表單部分目前使用 Alert 暫代，後續可擴充完整的 `ion-modal` 表單。

## 驗證結果 (Results)
- 列表與刪除 API Mock 串接正常。
- 多國語系正常載入。
- 架構符合專案 `ui-standardize` 與模組化規範。
