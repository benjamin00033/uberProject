# Task Log: Dynamic Form Engine Implementation (Tree Structure & Multi-task)
## 任務目標 (Goal)
實作可巢狀擴充 (Tree Structure) 的動態表單引擎，並支援陣列多任務結構。

## 執行動作 (Actions Taken)
1. **升級型別定義**：在 `src/domain/dynamicForm/types.ts` 中新增 `children` (供群組巢狀使用) 與 `itemSchema` (供陣列動態擴充使用) 屬性。
2. **開發 FormFieldRenderer**：建立 `src/domain/dynamicForm/components/FormFieldRenderer.vue`。實作遞迴元件，將 Schema 渲染為對應的表單 UI (`BaseInput`, `BaseSelect`, `BaseAccordion` 等)。
3. **升級 Builder 畫布**：在 `DynamicFieldBuilder.vue` 增加 `group`, `accordion`, `array` 型別選項，並針對這些型別提供對應的子層/項目編輯介面 (新增/移除子欄位)。
4. **替換 DynamicField**：在 `dynamicForm.vue` 中移除舊有的 `DynamicField`，全面導入支援巢狀的 `FormFieldRenderer`。
5. **多語系 (i18n-generator)**：將 `FormFieldRenderer` 和 `DynamicFieldBuilder` 中寫死的中文抽出，並加入至 `src/locale/language.ts` (`zh` 與 `en` 的 `dynamicForm` 節點)，並全面替換為 `useI18n()`。

## 遇到問題與解決 (Issues & Resolutions)
- 原有的 `builder.vue` 為重複 Scaffolding 的產物，已予以移除，保留已撰寫過內容的 `formBuilder.vue`。
- 多語系鍵值需要在陣列與巢狀結構中提供 `{label}` 參數來達到更通用的翻譯。

## 驗證結果 (Results)
- `vue-tsc --noEmit` 驗證全數通過 (無型別錯誤)。
- i18n 套用完畢，結構化正常。
