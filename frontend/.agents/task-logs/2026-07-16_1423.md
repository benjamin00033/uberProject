# Task Log: Fix BaseTabs routing error (Bug Fix)
## 任務目標 (Goal)
修正 `TestBaseUIPage.vue` 中使用 `BaseTabs` 造成的 `@ionic/vue` Router 錯誤 (`TypeError: Cannot read properties of undefined (reading 'getCurrentRouteInfo')`)。

## 執行動作 (Actions Taken)
1. **問題分析**：`BaseTabs` 原始實作用到了 `<ion-tabs>` 和 `<ion-router-outlet>`，但這個元件預期作為一個局部區塊的 UI 頁籤（並非 App 根部的全域 Navigation），因此導致了 router 找不到 context 的錯誤。且 `TestBaseUIPage.vue` 傳入的屬性為 `{ label, value }`，但原始 `BaseTabs` 卻要求 `tab` 和 `href`。
2. **重構 BaseTabs**：將 `<ion-tabs>` 替換為適合局部元件切換的 `<ion-segment>` 與 `<ion-segment-button>`。
3. **介面更新**：將 `TabItem` 介面修正為 `{ label: string; value: string; icon?: string }`，符合 `TestBaseUIPage.vue` 傳入的結構。
4. **測試修正**：更新 `BaseTabs.test.ts` 中的組件與事件以對應 `ion-segment` 的 `ionChange` 模擬。

## 遇到問題與解決 (Issues & Resolutions)
- 無

## 驗證結果 (Results)
- 在 TestBaseUI 頁面中，Tab 不會再拋出 Error，可以正常切換狀態 (modelValue 更新)。
- 相關的 Unit Test 也已修正。
