# 任務日誌：實作 Project Scheduler 時程表共用資料與拖曳提示

## 任務目標 (Goal)
將 `Dashboard.vue` 的寫死時程表改為動態根據目前的 `currentDate` 繪製，讓它能與 `CalendarView.vue` 共享相同資料格式。並新增拖曳改變任務起訖時間的支援，以及顯示滑鼠懸停提示。

## 執行動作 (Actions Taken)
1. 修改 `src/domain/projectScheduler/store/useProjectSchedulerStore.ts`：
   - 提取原本在 `CalendarView.vue` 內的 `currentDate`、`currentYearMonth`、`daysInMonth` 以及 `nextMonth` / `prevMonth`，改由 store 維護並 `export`。
2. 重構 `src/domain/projectScheduler/components/CalendarView.vue`：
   - 移除內部寫死的日期邏輯，直接從 store 取得 `daysInMonth`。
   - 新增任務卡片的 native `:title` 作為 tooltip，顯示專案名稱、日期範圍與狀態。
3. 重構 `src/domain/projectScheduler/pages/Dashboard.vue`：
   - 修改 `timelineHeader`，使用 `daysInMonth` 動態印出當月每一天的表頭。
   - 修改 `timelineTracks`，內部加入 `dayCell` 接收拖曳事件。
   - 更新 `getTaskStyle` 演算法，根據目前月份換算 `left` 與 `width` 百分比，並隱藏非本月任務。
   - 實作 `@dragstart` 與 `@drop` (利用 `updateTaskDates` 更新 task 起訖)。
   - 在任務條新增 `:title` 提示框。
4. 更新 `src/domain/projectScheduler/pages/Dashboard.module.scss`：
   - 使用 flexbox 均分 `daysHeader` 的每一天。
   - 移除舊有 `background-image` 計算，改為真實 `dayCell` 的 border，以利精準對應日期區域。
5. 驗證：
   - 執行 `npx vitest run src/domain/projectScheduler` 測試全數通過（11 passed）。
   - 執行 `npx vue-tsc --noEmit` 型別檢查通過。

## 遇到問題與解決 (Issues & Resolutions)
無特別問題，僅在重構時程比例時，特別計算任務起訖於月底/月出的邊界條件限制 (`Math.max(startMs, taskStart)`)，確保 UI 不會溢出 `100%` width 或負 `left`。

## 驗證結果 (Results)
- `Dashboard` 能正確根據 store 切換月份。
- 時程表任務能拖放改變日期，並觸發撞期紅框。
- Tooltips 運作正常，所有單元測試皆正常。
