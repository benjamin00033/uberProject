# Task Log: 新增 Web Worker 來處理 API 請求與計時器

## 任務目標 (Goal)
- 建立 `src/helper/worker` 資料夾，統一管理 Web Worker。
- 實作 API Worker (`apiWorker.ts`)：接收 API url、payload 與 action，透過 Axios 執行請求並回傳。
- 實作 Timer Worker (`timerWorker.ts`)：透過 Web Worker 定時器抓取並每分鐘回傳一次當地時間。
- 將 Timer Worker 整合至 `src/components/Layout/LayoutHeader.vue` 中，顯示在 Logout 按鈕旁。

## 執行動作 (Actions Taken)
1. 在 `src/helper/worker/` 目錄中建立了 `apiWorker.ts` 與 `timerWorker.ts`。
   - `apiWorker.ts` 利用 axios 發出對應 action 的請求。
   - `timerWorker.ts` 設定 `setInterval` 來每分鐘發布一次時間。
2. 為兩個 Worker 分別撰寫了單元測試 `apiWorker.spec.ts` 與 `timerWorker.spec.ts`，並為了測試容易度將 Message Handler 獨立抽出，方便使用 `vitest` 的 Mock 進行驗證。
3. 修改 `LayoutHeader.vue`，在 `onMounted` 時啟動 `timerWorker`，並在 `onUnmounted` 時執行 `terminate()` 與 `clearInterval()`，確保記憶體回收與防止定時器洩漏。
4. 在 `LayoutHeader.module.scss` 內加入了 `.timeDisplay` class，讓時間字體與版面保持簡潔。
5. 完成實作並確保 Vitest 與 vue-tsc 檢查順利通過。

## 遇到問題與解決 (Issues & Resolutions)
- **環境問題**：Web Worker 中預設難以執行 `axios`，但因為專案建置工具為 Vite，允許透過 `?worker` / `{ type: 'module' }` 等形式將 Worker 以 ESM 匯入並將 `axios` 打包處理。
- **測試問題**：Web Worker 中的 `self.onmessage` 不易在 JSDOM 或 Node 中直接測試。解法是將內部邏輯抽出為可測試的 function (`handleApiMessage` 與 `handleTimerMessage`)，於測試檔中 mock 依賴 (如 `axios` 與 `setInterval`)。

## 驗證結果 (Results)
- 單元測試 (`apiWorker.spec.ts`, `timerWorker.spec.ts`) 已完成並通過。
- 針對新檔案 `npx vue-tsc --noEmit` 無型別錯誤。
- 已撰寫並 commit 完成（Commit: `feat(worker): add apiWorker and timerWorker with tests and integrate timer to LayoutHeader`）。
